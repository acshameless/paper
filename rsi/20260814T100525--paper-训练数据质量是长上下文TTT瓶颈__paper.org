#+title: 训练数据质量是长上下文TTT瓶颈
#+subtitle: Self-Guided Test-Time Training for Long-Context LLMs
#+source: https://arxiv.org/abs/2607.09415v1
#+authors: Xinyu Zhu, Zhe Xu, Xiaohan Wei, Yunchen Pu, Fei Tian, Chonglin Sun, Kaushik Rangadurai, Hua Zhi, Frank Shyu, Sandeep Pandey, Luke Simon, Yu Meng, Xi Liu
#+venue: arXiv 2026 (Meta AI, University of Virginia)

* 速读

- *问题*：测试时训练（TTT）在长上下文 LLM 上，拿随机片段做适应反而让准确率从 40.4% 掉到 38.9%——训了不如不训。
- *洞见*：瓶颈不在适应机制，在训练数据质量。模型自己能选出该学什么片段；在自选片段上做 TTT，准确率升到 45.9%（预言片段上限），实际自选也能稳定超过基线。
- *启发*：做 TTT 时，先问"拿什么训"，再问"怎么适应"。模型自身的判断力就是最好的数据筛选器。

* 它到底在解决什么

一切从一个反直觉的实验开始。

作者在 LongBench-v2 上跑 Qwen3-4B-Thinking-2507，基础模型准确率 40.4%。然后他们做了最朴素的 TTT：
从长上下文里随机截一段，让模型在这段上做 next-token 预测来更新参数（LoRA，16 步），再用更新后的模型回答问题。

结果：38.9%。*训了反而更差。*

这和 TTT 在视觉领域的成功形成尖锐对比。问题出在哪？是适应机制本身有问题，还是别的什么？

作者做了一个关键的控制实验——"预言片段 TTT"：用 GPT-5.5 标注出与问题真正相关的片段，控制片段长度与随机片段可比，然后在这些片段上做 TTT。

结果：45.9%。*大幅提升。*

#+begin_example
  基础模型          40.4%
  随机片段 TTT       38.9%  ← 训了更差
  预言片段 TTT       45.9%  ← 训了更好
       │
       └─ 片段长度可比 → 隔离出"训练数据质量"这一变量
#+end_example

同一套适应机制、同一套 LoRA 配置、同一套训练步数，唯一变量是"拿什么片段训"。随机片段让模型在无关文本上拟合，把参数往错误方向推；预言片段让模型在相关文本上拟合，参数朝正确方向移动。

结论很硬：**TTT 的瓶颈不是"怎么适应"，是"拿什么训"。**

* 它真正看见了什么

**方法：S-TTT（Self-Guided Test-Time Training）**

两阶段，极简：

#+begin_example
  ┌─────────────────────────────────────────────┐
  │  阶段 1：模型引导的片段选择                    │
  │                                               │
  │  输入：完整上下文 x + 问题 q                   │
  │  模型读取全文，返回与问题相关的逐字片段          │
  │  S(x,q) = {x[s_j:e_j]}  (j=1..M)             │
  │                                               │
  │  → 如果模型未能生成有效片段，回退到随机片段      │
  ├─────────────────────────────────────────────┤
  │  阶段 2：在选定片段上做 TTT                    │
  │                                               │
  │  从 θ 的全新副本 θ' 开始                       │
  │  L_TTT(θ') = -Σ log p_θ'(x_i | x_<i)        │
  │  LoRA: rank=16, alpha=32, 仅 query 投影层     │
  │  AdamW, 16 步, lr ∈ {3e-5, 1e-4, 3e-4}      │
  ├─────────────────────────────────────────────┤
  │  推理                                         │
  │                                               │
  │  更新后的 θ' 从 *完整上下文* + 问题生成答案     │
  │  （注意：训练只用片段，生成用全文）              │
  └─────────────────────────────────────────────┘
#+end_example

一个细节值得注意：训练时只看选定片段，但生成答案时用完整上下文。TTT 改变的是模型参数（"模型怎么看"），不是输入（"模型看什么"）。

**关键结果**

在 LongBench-v2 和 LongBench-Pro 两个基准上，S-TTT 在所有 TTT 变体中始终最优或持平：

#+begin_example
                    LongBench-v2          LongBench-Pro
                  <64k    64k-128k      <64k    64k-128k
  ─────────────────────────────────────────────────────────
  Qwen3-4B
    基础模型       46.7     30.7         55.1     41.6
    S-TTT         47.7     35.3         56.2     42.0
    完整上下文TTT   46.7     31.0         55.3     41.7
    随机片段TTT    45.5     29.0         54.8     40.9

  Llama-3.1-8B
    基础模型       36.9     26.3         28.2     19.4
    S-TTT         38.4     28.2         29.9     21.7
#+end_example

两个模式：

1. *长上下文区间提升更明显*。Qwen3-4B 在 64k-128k 区间，LongBench-v2 上从 30.7→35.3，相对提升 15%。上下文越长，随机片段越可能无关，自选片段的价值越大。
2. *完整上下文 TTT 几乎不涨*。把整个长上下文都拿来训，效果和基础模型差不多——因为大量无关文本稀释了有用梯度信号。这进一步印证"数据质量 > 数据量"。

**片段选择：模型标注 vs 困惑度/熵**

一个自然疑问：能不能用更便宜的信号（困惑度、熵）来选片段，而非让模型标注？

#+begin_example
  Qwen3-4B, LongBench-v2
                    <64k    64k-128k
  模型标注           47.7     35.3
  困惑度得分         46.7     31.9
  熵得分             45.1     33.0
#+end_example

模型标注胜出，尤其在长上下文区间（35.3 vs 31.9/33.0）。有用的 TTT 片段不仅仅是"令人惊讶"或"不确定"的片段——它需要与问题语义相关，这是困惑度和熵捕捉不到的维度。

**注意力可视化：TTT 做了什么？**

S-TTT 后，模型对选定片段的注意力增加且变得更连续，尤其在中层。变化是局部的——暖区域与训练 token 对齐，其他地方接近零。TTT 不是全局调参，是在参数里给相关片段"开了一条高速公路"。

**效率**

S-TTT 在短上下文上比完整上下文 TTT 更慢（多了一个选择阶段），但从 64k 开始反超。128k 时，S-TTT 在所有非冻结 KV 的 TTT 方法中延迟最低。
模型标注的片段更局部（有效窗口 0.39C vs 随机片段的 0.50C），训练更快收敛。

* 我能带走什么

**判断规则：做 TTT 时，先问"拿什么训"，再问"怎么适应"。**

这条规则不限于长上下文 LLM。任何测试时适应场景——视觉 TTT、少样本微调、in-context learning 的梯度版——都面临同一个问题：适应用的数据是否与测试任务相关。
在无关数据上做梯度更新，不是"没效果"，是"负效果"。

**模型自身的判断力就是最好的数据筛选器。**

这篇论文最省力的读法是"又一个 TTT 变体"，但真正的贡献是那个控制实验：随机片段 vs 预言片段，长度可比，唯一变量是数据质量。
这个实验把"TTT 瓶颈在哪"这个问题从模糊变成可操作——不是去发明更好的适应算法，而是去发明更好的数据选择机制。

**一个留白**：回退率（模型选不出有效片段时退回随机）在 LongBench-Pro 上高达 21.5%（Qwen3）和 39.9%（Llama）。
模型越弱，自选能力越差，S-TTT 的收益越依赖模型本身的能力。这暗示一个递归问题：能不能用 TTT 来改进模型选片段的能力？用 TTT 改进 TTT 的数据选择——这正好是"改进改进方式"的又一个实例。
