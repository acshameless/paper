#+title:      探索本能可训练，推理时不再需要奖励
#+subtitle:   Training LLM Agents for Spontaneous, Reward-Free Self-Evolution via World Knowledge Exploration
#+source:     https://arxiv.org/abs/2604.18131
#+authors:    Qifan Zhang, Dongyang Ma, Tianqing Fang, Jia Li, Jing Tang, Nuo Chen, Haitao Mi, Yan Wang
#+venue:      arXiv 2026 (Tencent & HKUST-Guangzhou)

* 速读

现有的"自我进化"agent 其实是个幻觉——一旦撤掉人类定义的任务和奖励，进化就停了。
这篇论文的做法是：训练阶段用"自生成的环境知识能提升多少下游成功率"作为奖励信号，教会模型如何自主探索和压缩环境信息；
推理阶段完全不需要奖励或人类指令，模型自发探索新环境、生成一份结构化的"世界知识"（World Knowledge），再用它解题。
在 WebVoyager 和 WebWalker 上拿到约 20% 的绝对提升，而且这份知识可以跨模型迁移——14B 模型带上它甚至超过了裸跑的 Gemini-2.5-Flash。
带走一个判断：评估一个 agent 是否真正自主，先看它能不能在无任务、无奖励时主动理解环境。

* 它到底在解决什么

一个 agent 被放进一个全新的网站，在没有任何任务指派、没有任何奖励信号的情况下，它会做什么？今天的 agent 什么都不会做——它等着你给它一个任务，等着你告诉它做对了没有。
论文把这种状态叫"反应式"（reactive）：每一步动作都依赖于一个预定义的目标和一个外部观测。

现有的"自我进化"方案没有跳出这个框。一类是经验驱动：人类设计任务和奖励函数，agent 反复尝试、积累经验、更新自己。
另一类是对抗驱动：一个 agent 出题、另一个解题，看似自动，但协作流程仍需人工搭建。两类方案的本质相同——去掉人类定义的奖励和任务，进化立刻停止。作者认为这不是真正的自主。

问题出在哪？agent 缺少一种"先理解环境、再执行任务"的本能。人类到了一个新城市，会自发地摸清布局和逻辑，不需要先有人布置任务。这种探索和压缩环境信息的能力，现有 agent 没有，也没有被训练过。

* 它真正看见了什么

可以用一句话说清：探索和总结环境信息的能力，可以通过"下游效用量化"来训练，训练好后推理时不再需要任何奖励。

核心机制是一个两阶段生命周期：

#+begin_example
训练阶段（有奖励，教会"怎么探索"）:
  环境 → Agent 探索 → 生成 K → 用 K 做下游任务
                                   ↓
                   R = Success(有K) − Success(无K)
                                   ↓
                       SFT（教师模仿）+ RFT（拒绝采样）→ 更新模型

推理阶段（无奖励，自发执行）:
  新环境 → 训练好的 Agent 自发探索 → 生成 K → 用 K 解题
#+end_example

K 是一份 Markdown 格式的结构化文档，相当于 agent 给环境画的"心智地图"。训练时的奖励公式就是核心洞见的最短表达：

R(K) = Success(T|K) − Success(T|∅)

翻译成人话：你生成的环境知识好不好，不看它长不长、像不像，只看它能不能让 agent 在这个环境里把任务做得更好。这个信号只在训练时用，用来教模型学会"探索什么、压缩什么"。模型学会之后，推理时自发执行，不需要任何外部奖励。

训练分两步：先用 Gemini-2.5-Pro 作为教师模型生成高质量探索轨迹做 SFT，再用拒绝采样微调（RFT）迭代两轮自我优化。
关键设计是：奖励评估需要跑一整套下游任务来衡量 K 的效用，计算代价极高，所以不能做标准在线 RL，只能用离线拒绝采样。

证据有两个改变判断的结果：

第一，在 Qwen3-30B 和 Seed-OSS-36B 上，训练后的模型在 WebVoyager 和 WebWalker 上比无知识基线高约 20% 绝对值。
更值得注意的是，未训练的基座模型用同样的 prompt 去探索，生成的 K 反而降低了成功率（WebWalker 上从 22% 掉到 19.5%）——说明探索和压缩不是天生就会的，乱探索比不探索更糟，训练确实教会了模型区分信号和噪声。

第二，K 是模型无关的。Seed-36B 生成的 K 给 Qwen3-14B 用，平均提升 18.3%；给 Kimi-K2-Turbo 用，提升 21%。
最极端的对比：14B 的 Qwen3 带上 K，在 Conference 和 Game 两个领域超过了裸跑的 Gemini-2.5-Flash。这说明在 web agent 场景下，对环境的精确知识比模型参数规模更关键。

这些结果只在 web 导航场景下成立。训练集是 20 个网站的 600 个问题，评测集 1427 个样本，都是 web 任务。
论文没有证明这种范式能迁移到代码、游戏以外的环境。K 的质量对 token 长度敏感：太短丢信息，太长引入噪声，16k-32k 是甜点区，再长反而略降。

* 我能带走什么

以后看到"agent 自我进化"，先不急着判断它比上代强多少，而先问一个问题：去掉人类定义的任务和奖励后，它还能不能自己动？如果不能，它只是在更复杂的人工脚架里跑，不是真正的自主。

一个相关用法：如果你在构建 agent 系统，考虑把"环境理解"和"任务执行"拆成两个阶段——先让 agent 花时间探索环境、压缩成可复用的知识文档，再用它解题。这份知识可以跨模型、跨任务复用，比每次从零探索更高效。
