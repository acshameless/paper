#+title:      后见之明可以蒸馏回策略参数
#+subtitle:   SEED: Self-Evolving On-Policy Distillation for Agentic RL
#+source:     https://arxiv.org/abs/2607.14777
#+authors:    Jinyang Wu, Shuo Yang, Zhengxi Lu, Fan Zhang, Yuhao Shen, Lang Feng, Haoran Luo, Zheng Lian, Shuai Zhang, Zhengqi Wen, Jianhua Tao

* 速读

长视野 agent 任务里，结果导向的 RL 只在轨迹结束时给一个成功或失败的标量——一条 30 步的失败轨迹可能只有第 21 步走错了方向，但奖励无法区分。
SEED 的核心观察是：完成的轨迹里藏着在线决策时看不到的后见之明（哪些子目标达成了、哪个观察是决定性的、哪种行为模式可以复用）。
它把同一批采样动作在两种上下文下重新打分——普通上下文（学生）和技能增强上下文（老师）——概率偏移变成逐 token 的稠密训练信号，蒸馏回策略参数。
同一个模型同时当演员和分析者，策略更新后两个角色一起进步，后见之明随策略共进化。推理时不需要技能提示，部署零额外开销。
实验显示 SEED 用 60% 训练数据就超过 GRPO 全量数据的水平，且在未见任务上平均提升 15 个百分点。以后设计 agent RL 时，不要只问"轨迹得了什么奖励"，而要问"完成轨迹里有哪些后见之明可以提取出来、蒸馏回参数"。

* 它到底在解决什么

一个 agent 在 ALFWorld 里执行 30 步操作，最终失败了。RL 只知道"失败"这个事实，但其中第 5 步到第 20 步可能完全正确，只是第 21 步走错了方向。
反过来，一条成功的轨迹可能包含一套可复用的工作流——先找物体、去清洗站、清洗、再放到目标位置——但标量奖励从不告诉你哪些决策是关键。

这就是长视野 agent RL 的核心困难：环境只在轨迹级别给反馈，而策略需要在 token 级别学习。
这个粒度差距意味着，失败轨迹里的有用局部行为被一起惩罚了，成功轨迹里的可复用策略被一起奖励了——信用分配无法到达单个决策。

人们原来的处理方式有几种。一是结果导向的 RL（如 GRPO），直接用轨迹级奖励优化，接受稀疏信号的限制。二是把后见之明存成静态经验库或推理时上下文（如 Reflexion 的语言反思、 episodic memory），但这些方法把 hindsight 当成固定资产——存一次、检索一次，不随策略变化。三是用外部教师或一次性技能数据集做蒸馏，但教师是静态的，策略进步后教师的指导就过时了。

这些做法的共同问题是：后见之明被当成静态资源，而不是随策略进化的活信号。策略变强后遇到的新状态、新失败模式，旧的后见之明已经不匹配了。

* 它真正看见了什么

完成轨迹里的后见之明不必停留在外部记忆或推理提示里——它可以被蒸馏回策略参数本身，而且应该随策略一起进化。

SEED 的机制分两层。第一层是"同一个模型演两个角色"的自进化环：当前策略快照既收集轨迹，又分析完成轨迹提取自然语言技能。策略更新后，两个角色一起刷新——决策能力和技能分析能力共同进步。
第二层是"同一批动作两种上下文"的蒸馏机制：对每个采样动作，在普通上下文（学生分支，梯度流过）和技能增强上下文（老师分支，截断梯度）下分别计算 log 概率。概率偏移经过 sigmoid 门控后变成逐 token 的稠密信号。

#+begin_example
  ┌──────────── self-evolving loop ────────────┐
  ▼                                            │
 同一个 πθ_old                                 │
  ├── 收集轨迹 (actor)                          │
  └── 分析轨迹 → 后见技能 (analyzer)            │
                    │                           │
  同一批采样动作，两种上下文重打分：              │
  ┌──────────────┼──────────────┐              │
  │ 学生: 普通上下文  ← 梯度流   │              │
  │ 老师: 技能上下文  ← 截断    │              │
  └──────────────┼──────────────┘              │
  概率偏移 → 置信门 → 稠密 token 信号           │
                    │                           │
  L = L_RL + λ·L_OPD → 更新 πθ                 │
                    └───────────────────────────┘
#+end_example

核心关系可以用一行公式抓住：

L_OPD = E[m · g · (sg[ℓ_skill] - ℓ_θ)]，其中 g = σ(β · (ℓ_skill - ℓ_θ))

人话翻译：老师分支（看到技能）和学生分支（只看普通上下文）对同一批 token 打分。
如果技能支持某个 token，老师给更高概率，偏移为正，门控放大这个信号；学生被拉向老师支持的行为。梯度只流过学生分支，所以技能的行为效果被内化进策略参数，推理时不需要技能。

这个设计的关键在于：技能只在训练时作为特权上下文存在，推理时完全移除。策略"吸收"了技能的指导，而不是依赖它。

证据方面，两个结果较稳地改变了判断：

第一，样本效率。在 ALFWorld 上，SEED 用 60% 的训练数据达到 80.7，超过 GRPO 用全量数据的 75.0。这说明稠密的后见之明信号不是在稀疏奖励上做边际改进，而是让每条轨迹的利用效率发生了质变——失败轨迹里的正确决策不再被浪费，成功轨迹里的可复用策略被显式提取并内化。

第二，跨域泛化。在 ALFWorld Unseen（训练时没见过的任务类别）上，SEED 平均成功率从 70.9 提升到 86.2，其中 Heat 类别提升 35 个百分点。这说明内化进参数的不是特定任务的操作序列，而是可迁移的行为指导（如"先确认物体状态再移动"）。
在多模态扩展中（Sokoban 和 EZPoints），SEED 也比 GRPO 平均高 14 个百分点，说明机制不限于文本交互。

但这些结果有边界。自进化环有一个结构性风险：演员和分析者共享同一组参数，盲区也共享。一个不准确的分析可能把反复出现的策略错误变成"看起来可复用的规则"，后续更新还会强化它。
论文在讨论部分诚实承认了这一点——on-policy 对齐和置信门控能减少分布不匹配和噪声，但既不保证语义正确性。实验也限于中等复杂度的 benchmark（最多 30 步交互），更长、更复杂的环境是否仍能保持后见之明的有效性，尚未验证。

* 我能带走什么

以后看到 agent RL 只用稀疏轨迹级奖励，先不急着判断"奖励太稀疏，需要更好的奖励塑形或过程监督"，而先问：完成轨迹里有哪些后见之明可以提取出来，蒸馏回策略参数？

这个问题的转变在于：与其从外部找更细的奖励信号，不如从策略自己产生的完成轨迹里提取稠密监督。后见之明不是静态资产，而是随策略进化的活信号——前提是分析者和演员共享同一组参数，一起更新。

一个相关用法：当发现固定教师或静态技能数据集在训练后期效果衰减时，检查是否是"分析者过时"——策略已经遇到了旧技能覆盖不到的新状态和失败模式。SEED 的自进化环通过刷新共享检查点来重置这种不匹配。

另一个相关用法：当 agent 在推理时依赖外部记忆或技能提示才能表现好，说明行为指导还停在外部，没有被内化进参数。SEED 的蒸馏机制把"看到技能才做对"变成"不看到技能也做对"。
