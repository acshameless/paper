#+title:      记忆写进参数才能改变策略
#+subtitle:   Scaling Self-Evolving Agents via Parametric Memory
#+source:     https://arxiv.org/abs/2606.04536
#+authors:    Tao Ren, Weiyao Luo, Hui Yang, Rongzhi Zhu, Xiang Huang, Yuchuan Wu, Bingxue Chou, Jieping Ye, Jiafeng Liang, Yongbin Li, Yijie Peng
#+venue:      arXiv 2026 (Alibaba / Peking University)

* 速读

长程 agent 把经验只存在提示空间（摘要或检索），模型参数始终冻结——经验只有被重新塞回上下文才能影响后续行为，一旦被压缩掉就永久丢失。
TMEM 让 agent 在上下文超预算时把当前会话蒸馏成 QA 对，用几步在线 SFT 写进 LoRA 权重，使策略本身在单次 episode 内发生变化。
这把"记忆提取"从预处理变成了可优化的动作：RL 不仅训练基础模型解题，还训练它产出能让自己的未来快速权重更新更有用的监督。
四个 benchmark 上一致超过摘要和检索基线，且 RL 增益最大——说明参数化记忆是长程 agent 值得拉的杠杆。

* 它到底在解决什么

一个多轮对话 agent 跑了很长，早期会话被摘要压缩以省上下文。后来用户问起第二会话里的一个具体数字——某人在集市上赚了多少钱。
摘要把这个数字丢了，agent 查不回来。即使用检索，如果 embedding 和查询不够匹配，也可能漏掉。信息曾经在那里，被压缩掉了，再也没有路径回到策略里。

这不只是压缩质量问题，而是结构性的：所有现有记忆 agent（摘要式、检索式）在 episode 内模型参数始终不变。agent 能查阅存储的经验，但不能把它内化进后续决策所用的计算。
一旦证据从上下文中消失，它对策略就永久失去了影响。模型在第一步和第一百步是同一个冻结的模型——经验只改了提示，没改策略。

* 它真正看见了什么

记忆应该被写进快速权重（LoRA），让蒸馏出的经验改变策略本身，而不只是占据提示。

当工作上下文达到预算 L_max 时，agent 进入记忆写入模式：把当前会话蒸馏成有据可查的 QA 对（不是自由摘要），用这些 QA 对做轻量在线 SFT，更新 LoRA 权重 Δ_t → Δ_{t+1}，然后清空工作上下文。
后续动作从适应后的策略 π_{θ₀+Δ_{t+1}} 采样，而非冻结的基础模型。

#+begin_example
  正常交互  a_t ~ π(θ₀ + Δ_t)
  上下文持续增长 ...
      │
      │  上下文 > L_max
      ▼
  蒸馏会话 → QA 对
      │
      ▼
  在线 SFT:  Δ_t → Δ_{t+1}
  (SVD 初始化 LoRA, 5 epochs)
      │
      ▼
  清空上下文, 用 π(θ₀+Δ_{t+1}) 继续
      │
      └─── 回到正常交互
#+end_example

TMEM 与现有方法的结构差异：

| 方法     | 记忆存在哪里      | 策略在 episode 内变化？ |
|---------+------------------+------------------------|
| 无记忆   | 上下文            | 否                     |
| 摘要式   | 提示文本          | 否                     |
| 检索式   | 外部索引          | 否                     |
| TMEM    | 快速权重 (LoRA)   | 是                     |

两个设计选择显著影响效果：

**SVD 初始化。** 标准 LoRA 随机初始化投影矩阵 A，在线更新只有少量梯度步（每次触发 5 epochs），随机子空间浪费早期步数去"发现"该往哪个方向适应。
TMEM 用预训练权重的 top-r 奇异向量初始化 A 并冻结，只更新系数矩阵 B——把更新锚定在高能量方向上。在 LoCoMo 上，SVD 初始化比随机初始化高 +3.25 EM，增益集中在精确召回而非模糊覆盖。

**QA 对作为监督。** 消融显示监督形式的影响很大：QA 对 >> 自由摘要 >> 原始下一词预测。原始预测让模型逐字复现上下文，自由摘要提供高层抽象但缺乏查询结构，QA 对显式编码了与下游查询对齐的问答结构。
在 LongMemEval-S 上，QA 对比摘要高 +5.80 F1。

RL 阶段用 stop-gradient 策略优化：梯度不回传过在线 LoRA 更新算子 T，而是训练 θ₀ 产出更好的任务动作和更好的提取动作（让未来权重更新更有用的 QA 对）。
RL 后 TMEM 增益最大：LoCoMo 上 +5.12 F1，而摘要式仅 +2.62。这提示当记忆能适应快速权重时，RL 的收益更大。

这些结果在四个 benchmark 上一致，但分寸不同：LongMemEval-S 上 8B 模型增益最大（+10.21 F1），搜索任务上 8B 的 4-objective 增益较小（+1.00 F1），作者自己称之为"方向性而非决定性"。
CL-Bench 结果基于从 1899 条中筛出的 289 条可区分子集；在未筛选全集上所有方法都在 5% 附近。
TMEM 的计算开销介于摘要和检索之间：LoCoMo 上 1.53 s/ep vs 摘要 0.94 s、检索 2.03 s，GPU 显存 21.3 GB vs 摘要 11.2 GB。

* 我能带走什么

以后做长程 agent，不要只问"存什么、怎么检索"——先问"模型能在测试时把存下的经验内化进参数吗？"如果策略在 episode 内始终不变，记忆就只是查询表，从上下文中丢掉的证据对策略永久失去影响。

一个具体用法：当 episode 超出上下文窗口时，与其只做摘要压缩，不如把会话蒸馏成 QA 对并做几步在线 LoRA 更新——让策略带着经验继续，而不是带着空手继续。
