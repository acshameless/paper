#+title:      冻结模型缺的不是能力而是调度器
#+subtitle:   RISER: Orchestrating Latent Reasoning Skills for Adaptive Activation Steering
#+source:     https://arxiv.org/abs/2601.09269
#+authors:    Wencheng Ye, Xiaoyang Yuan, Yi Bin, Hengyu Jin, Liang Peng, Pengpeng Zeng, Heng Tao Shen

* 速读

激活引导（activation steering）用一根固定向量、一个手调强度对待所有输入，相当于给大脑装了一个只会发一种信号的前额叶。
RISER 从冻结模型的激活空间里提取出六根近正交的推理方向（数值计算、逻辑推理、伦理对齐等），再训练一个仅占模型 0.1% 参数的轻量路由器，让它根据当前输入动态选择并组合这些方向。
关键发现是：监督学习只能学会"哪个任务用哪根向量"，而 RL 精炼能发现多根向量的协同组合——这种组合在跨领域任务上贡献最大。
以后看到冻结模型在多样推理任务上表现不稳，先别急着重训练或加长思维链，而要先问：模型内部是否已有对应能力，缺的只是一个知道何时激活哪组能力的调度器。

* 它到底在解决什么

一个模型做数学题时需要数值推理，做伦理判断时需要道德对齐，做跨学科综合题时两者都要。
但现有的激活引导方法——不改模型权重、直接在中间层激活上加一个方向向量来引导推理——只用一根向量、一个固定强度对待所有输入。
这就像前额叶只能发出一种控制信号：不管你在算数还是在做伦理判断，它都给你同样的"多想一点"。

这种静态控制有两个失灵点。一是表达力不够：复杂推理是多面的，一根向量无法同时编码数值计算和逻辑推理。二是不自适应：同一根向量在数学题上有用，在伦理题上可能是噪声。
此前有人尝试给单根向量加门控或动态强度，但都没有解决"如何组合多根能力向量"的问题，而且仍依赖监督目标训练。

认知神经科学早就给出了另一种蓝图：人脑的功能是模块化的，前额叶皮层（PFC）通过动态路由控制信号来协调不同模块。
表示工程的研究也表明，LLM 的激活空间里确实存在可解释、语义有意义的方向，对应不同技能和推理模式。
这两条线索合在一起指向一个问题：能不能在冻结模型里建一个 PFC 式的控制器，按需唤醒和组合潜在认知能力？

* 它真正看见了什么

冻结模型的激活空间里已经藏着多根近正交的推理方向；缺的不是能力本身，而是一个知道何时激活哪组能力的调度器。

RISER 的机制分三步走：

#+begin_example
  离线 A：建向量库                离线 B：训路由器          在线：动态引导
  ┌─────────────────┐       ┌──────────────────┐     ┌────────────────────┐
  │ 对比激活提取     │       │ 监督预热          │     │ 输入 → 走到第 l 层  │
  │ (正/负提示对)    │──┐    │ (网格搜索找最优   │     │ 读最后 token 隐状态 │
  │      ↓          │  │    │  组合做标签)      │     │      ↓              │
  │ LLM-Judge 过滤   │  ├──→│      ↓           │──→  │ 路由器输出：        │
  │      ↓          │  │    │ RL 精炼 (GRPO)   │     │ 选择掩码 w + 强度 α │
  │ K-Means 聚类     │  │    │ (任务级准确率奖励│     │      ↓              │
  │ → 6 根正交向量   │  │    │  + KL 正则)      │     │ 组合向量注入第 l 层 │
  └─────────────────┘  │    └──────────────────┘     │      ↓              │
                       └──────────────────────────────→ 模型从 l+1 层继续  │
                                                      └────────────────────┘
#+end_example

核心注入操作可以用一行表达：

v_inject = Σ (w_i · α_i · v_i)，  h'_l = h_l + v_inject

翻译成人话：路由器对每根向量 v_i 输出两个数——选不选（w_i，0 或 1）和推多猛（α_i，连续值），把它们加权求和后加到第 l 层的隐状态上。
模型从这里继续往前算，就像内部状态被轻轻拨向了需要的推理方向。双头设计把"用哪些能力"（离散选择）和"用多大力"（连续强度）解耦，既稀疏又灵活。

三个证据改变了判断：

**RL 精炼发现了监督学习发现不了的组合。** 消融实验中，只用监督预热的路由器在 GPQA 上只有 31.2%，加上 RL 精炼后跳到 36.8%；TruthfulQA 从 54.6% 到 59.8%。监督学习只能学会"哪个任务用哪根向量"，
而 RL 在任务级准确率奖励下自由探索组合空间，发现了多根向量的协同效应——这在跨领域任务（如 GPQA 需要同时调用科学分析和领域知识）上贡献最大。

**收益来自架构，不是来自 RL 本身。** 把同样的 GRPO 预算直接花在全模型微调上（Direct GRPO），MATH 只有 47.6%，而 RISER 是 53.3%。同样的 RL 算法、同样的计算预算，
花在外部控制器上比花在模型权重上更有效——因为前者保留了模型原有能力，只增加调度，后者有灾难性遗忘风险。

**路由器学会了专精与组合的混合策略。** 热力图显示，MATH 和 GSM8K 强关联数值计算向量，Ethics 和 TruthfulQA 强关联伦理对齐向量——这是专精。
但 GPQA 同时激活了科学分析、领域知识、逻辑推理多根向量——这是组合。在单一认知需求的任务上，限制只用一根向量（Top-1）几乎不掉分甚至微涨；但在跨领域任务上，去掉组合就明显下降。

这些结果在四个模型（Qwen2.5-7B/14B/32B、Llama-3-8B）和七个基准上较稳地显示。但有几个边界：向量库固定为六类，是工程权衡，可能过度简化了激活流形；
向量主要捕获粗粒度领域级模式，更细的原子技能有待后续工作；跨模型族迁移无效——向量和路由策略与模型特定的表示几何紧耦合，同族不同参数规模可迁移，跨族不行。
此外，性能上限受限于基座模型预训练质量——RISER 是唤醒潜在能力，不能无中生有。

* 我能带走什么

以后看到冻结模型在多样推理任务上表现不稳，先别急着重训练或加长思维链，而先问：模型内部是否已有对应能力，缺的只是一个知道何时激活哪组能力的调度器？

一个相关用法：当你需要对模型施加不同推理引导（数学、伦理、阅读理解）但又不想改权重时，不要为每个场景单独调一根静态向量，而应考虑训练一个轻量路由器让它自己学组合——尤其在任务认知需求混合时，
组合比专精更有效。另一个用法：如果你在做 RL 微调但担心灾难性遗忘，可以试试把 RL 预算花在外部控制器而非模型权重上——同样的计算预算可能换来更好的效果和更小的副作用。
